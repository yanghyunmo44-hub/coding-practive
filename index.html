비밀번호가 안전한가요?

전 세계 데이터 유출 사고에서 내 비밀번호가 포함되었는지 즉시 확인하세요.

🔒 개인정보 보호 안내: 입력하신 비밀번호는 서버로 전송되지 않습니다. 브라우저 내에서 즉시 암호화(SHA-1) 처리되어 안전하게 대조됩니다.

📘 비밀번호 보안 가이드

1. 복잡성 유지

대문자, 소문자, 숫자, 특수문자를 혼합하여 최소 12자 이상의 비밀번호를 만드세요.

2. 사이트별 고유 비밀번호

하나의 비밀번호를 여러 사이트에서 재사용하지 마세요. 한 곳이 털리면 모든 곳이 위험해집니다.

3. 2단계 인증(2FA) 사용

비밀번호 외에 OTP나 SMS 인증을 추가하면 보안 계층이 하나 더 생겨 훨씬 안전합니다.

4. 비밀번호 관리자 활용

복잡한 비밀번호를 일일이 기억하기 힘들다면 Bitwarden이나 1Password 같은 관리 도구를 사용하세요.

❓ 자주 묻는 질문 (FAQ)

정말 비밀번호를 안 가져가나요?

네, k-Anonymity 모델을 사용하여 비밀번호의 해시값 앞 5자리만 전송하므로 원본 비밀번호는 절대 유추할 수 없습니다.

유출되었다고 나오면 어떻게 하나요?

해당 비밀번호를 사용하는 모든 사이트에서 즉시 비밀번호를 변경하고 2단계 인증을 설정하시기 바랍니다.
